---
title: "List API Keys"
api: "GET /api/api-keys"
description: "Retrieve all API keys for the authenticated user"
---

Get a list of all your API keys with their metadata. The full key value is never returned after creation.

<RequestExample>
```bash cURL
curl -X GET https://testlab.letsmake.com/api/api-keys \
  -H "X-API-Key: tlk_your_api_key_here"
```
</RequestExample>

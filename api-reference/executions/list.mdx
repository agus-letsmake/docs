---
title: "List Executions"
api: "GET /api/executions"
description: "Retrieve a list of all test execution runs"
---

Get all test executions with their results and status information.

<RequestExample>
```bash cURL
curl -X GET https://testlab.letsmake.com/api/executions \
  -H "X-API-Key: tlk_your_api_key_here"
```
</RequestExample>

<ResponseExample>

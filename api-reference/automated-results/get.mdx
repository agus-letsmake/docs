---
title: "Get Execution Results"
api: "GET /api/automated-results"
description: "Retrieve results for a specific execution (useful for CI/CD to check test status)"
---

Fetch the complete results and status of a test execution. This is useful for CI/CD pipelines to check if their tests passed or failed.

## Query Parameters

<ParamField query="executionId" type="string" required>
  The execution ID to retrieve results for
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://testlab.letsmake.com/api/automated-results?executionId=exec-abc123" \
  -H "X-API-Key: tlk_your_api_key_here"
```

```javascript JavaScript
const executionId = 'exec-abc123';
const response = await fetch(
  `https://testlab.letsmake.com/api/automated-results?executionId=${executionId}`,
  {
    headers: {
      'X-API-Key': process.env.TESTLAB_API_KEY
    }
  }
);

const data = await response.json();

// Check if any tests failed
if (data.summary.fail > 0) {
  console.error(`${data.summary.fail} tests failed!`);
  process.exit(1);
}

console.log(`All tests passed! (${data.summary.pass}/${data.summary.total})`);
```

```python Python
import requests
import sys

execution_id = "exec-abc123"
url = f"https://testlab.letsmake.com/api/automated-results?executionId={execution_id}"
headers = {"X-API-Key": os.environ["TESTLAB_API_KEY"]}

response = requests.get(url, headers=headers)
data = response.json()

# Check if any tests failed
if data["summary"]["fail"] > 0:
    print(f"{data['summary']['fail']} tests failed!")
    sys.exit(1)

print(f"All tests passed! ({data['summary']['pass']}/{data['summary']['total']})")
```

## Use in CI/CD

This endpoint is particularly useful for:

### Failing Builds on Test Failures

```bash GitHub Actions
- name: Run tests and push to TestLab
  run: |
    npm test -- --json --outputFile=results.json
    EXECUTION_ID=$(node scripts/jest-to-testlab.js results.json | grep -o 'exec-[a-z0-9]*')
    echo "execution_id=$EXECUTION_ID" >> $GITHUB_OUTPUT
  id: tests

- name: Check test results
  run: |
    curl -X GET "https://testlab.letsmake.com/api/automated-results?executionId=${{ steps.tests.outputs.execution_id }}" \
      -H "X-API-Key: ${{ secrets.TESTLAB_API_KEY }}" \
      > test-results.json
    
    FAILURES=$(jq '.summary.fail' test-results.json)
    if [ "$FAILURES" -gt 0 ]; then
      echo "::error::$FAILURES tests failed"
      exit 1
    fi
```

**Runs** lists executions with filters (All / Manual / Automated / In progress /
Completed). Automated CI runs show pass bars, branch, and CI links.

<img src="/images/screenshots/runs-list.png" alt="Runs list with Maestro and Playwright CI executions" />

## Run detail

Open a run to see pass/fail/skip counts, distribution, PDF export, and the case
result table. Failed automated cases are the usual entry point into evidence review.

<img src="/images/screenshots/run-detail.png" alt="Run detail showing pass rate and case results" />

  personal emails into documentation.

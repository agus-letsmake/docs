## List and filter

## Empty state

New projects show an empty prompt until you create or import cases:

<img src="/images/screenshots/cases-empty.png" alt="Empty cases state" />

## Import / Export (Portable Catalog)

Use **Import / Export** to load a [Portable Catalog](/concepts/portable-catalog).
Every case needs an `automationKey`. This is the supported bulk path — not CLI init.

## Create

**+ New Test Case** opens the create flow (`/test-cases/new`).

---
title: Case
description: "A test case with steps, labels, and optional automation key"
---

A **Case** is the atomic test definition: title, steps, expected results, labels,
epic/feature, priority, and automation status.

Automated reporting matches cases by **automation key** (from tags/title via the
Playwright adapter, or explicit keys in the Portable Catalog).

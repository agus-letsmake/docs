Use these terms consistently. They match the product `CONTEXT.md` language.

| Concept                                             | One-liner                                                   |
| --------------------------------------------------- | ----------------------------------------------------------- |
| [Project](/docs/concepts/project)                   | Tenancy boundary for cases, suites, keys, and members       |
| [Case](/docs/concepts/case)                         | A test case with steps, labels, and optional automation key |
| [Suite](/docs/concepts/suite)                       | A named grouping of cases for execution                     |
| [Execution (Run)](/docs/concepts/execution)         | A single run of cases — manual or automated                 |
| [Evidence](/docs/concepts/evidence)                 | Attachments and observed step screenshots for a result      |
| [API key](/docs/concepts/api-key)                   | Project-scoped credential for CI and SDKs                   |
| [Portable Catalog](/docs/concepts/portable-catalog) | JSON import shape requiring automation keys                 |
| [Reporting env](/docs/concepts/reporting-env)       | `TESTLAB_*` variables written by CLI init                   |

```mermaid
flowchart TB
  Project --> Cases
  Project --> Suites
  Suites --> Cases
  Project --> Executions
  Executions --> Results
  Results --> Evidence
  Project --> ApiKeys
```

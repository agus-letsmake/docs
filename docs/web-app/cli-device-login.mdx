---
title: CLI device login
description: "Approve a CLI login from the browser"
---

When you run `npx testlab login`, the CLI opens (or prints) a device login URL
served at **`/cli/device`**. Sign in with Google/Firebase in the browser, approve
the code, and the CLI receives a short-lived **user** credential.

That credential is stored in a user-level CLI store (for example under
`~/.config/testlab/`) — **not** in the project `.env`.

<Info>
  Device login is separate from the CI API key written by `testlab init`.
</Info>

Under **Project** in the sidebar:

| Page | Purpose |
| --- | --- |
| General | Project name / metadata and **Notifications** (live Slack run cards) |
| Members | Invite and roles |
| API Keys | Create project-scoped CI keys |
| Automation | GitHub App / workflow wiring |

## API Keys

<img src="/images/screenshots/settings-keys.png" alt="Project API Keys empty state with CI curl example" />

Create a key, copy it once, and store it in your CI secret store. Always send
`X-Project-Id` with project-scoped keys.

## Notifications

On **General**, **Live run card** posts one Slack plan per automated execution and
updates it as results arrive. Invite the TestLab bot, paste a channel ID
(`C…` / `G…` / `D…`), save, then **Send test message**.

Full setup: [Live Slack run cards](/docs/guides/live-slack-run-cards).

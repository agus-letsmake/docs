title: Suites
description: "Group cases into suites for organized runs"
---

**Suites** appear as cards with case counts. Create with **+ New Suite**, then
link cases from the suite detail screen.

<img
  src="/images/screenshots/suites-list.png"
  alt="Suites grid including Maestro and Playwright nightly runs"
/>

CLI init does **not** create or link suites — manage them here (or via API).

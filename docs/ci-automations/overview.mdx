Two related surfaces:

1. **Reporting from CI** — Client / Playwright packages with `TESTLAB_*` secrets
2. **Automations** — in-app GitHub App wiring to dispatch workflows (`/automations`
   and Project → Automation)

Start with [GitHub Actions](/docs/ci-automations/github-actions) for the reporting
path, then [Automations](/docs/ci-automations/automations) if you need TestLab to
trigger workflows.

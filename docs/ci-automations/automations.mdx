TestLab can connect a GitHub App and dispatch workflows for a project.

## UI entry points

- Sidebar / hub: `/automations`
- Project settings: **Project → Automation**

## Typical flow

1. Install / authorize the GitHub App for the target org/repo
2. Configure mappings (suite ↔ workflow)
3. Trigger from the Automations UI or Run CI affordances
4. Results report back via the SDK using project API keys

API routes (Observed; OpenAPI sync in progress): `/api/automations/*`
(integrations, mappings, trigger, batches, preflight, GitHub callback).

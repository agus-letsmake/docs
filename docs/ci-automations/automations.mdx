TestLab can connect a GitHub App and dispatch workflows for a project.

## UI entry points

- **Runs** (`/executions`) — filter Automated, use **Run CI** when preflight is ready
- Project settings: **Project → Automation** (GitHub connect + suite mappings)
- Legacy `/automations` redirects to `/executions?kind=automated`

## Typical flow

1. Install / authorize the GitHub App for the target org/repo
2. Configure mappings (suite ↔ workflow) under Project → Automation
3. Trigger from **Run CI** on Runs (editor+; preflight must be ready)
4. Results report back via the SDK using project API keys

API routes are documented in the synced OpenAPI (`/api/automations/*`:
integrations, mappings, trigger, batches, preflight, GitHub callback).

## Prerequisites

- Access to a TestLab instance
- Node 20+
- A Playwright project (or use the Client package directly)

## Step 1: CLI setup

```bash
npm install @ovenbits/make-testlab-playwright @ovenbits/make-testlab-client
npx testlab login --url https://your-testlab-host
npx testlab init
```

This writes `TESTLAB_*` reporting env. Details: [CLI login + init](/docs/cli-sdk/cli-login-init).

## Step 2: Import cases

In the web app, open **Cases → Import / Export** and load a
[Portable Catalog](/docs/concepts/portable-catalog) with automation keys.

## Step 3: Register the reporter

```ts
import { defineConfig } from "@playwright/test";

export default defineConfig({
  use: { screenshot: "on" },
  reporter: [["list"], ["@ovenbits/make-testlab-playwright"]],
});
```

## Step 4: Push a run

```bash
export TESTLAB_PUSH=1
npx playwright test
```

Review the run under **Runs** in the web app.

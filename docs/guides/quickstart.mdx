## Prerequisites

Before you begin, make sure you have:
- A TestLab account
- Access to the TestLab dashboard

## Step 1: Generate an API Key

<Steps>
  <Step title="Log in to TestLab">
    Navigate to your TestLab instance and sign in
  </Step>
  <Step title="Go to Settings">
    Click on the Settings menu item
  </Step>
  <Step title="Create API Key">
    In the API Keys section, click "Create New API Key"
  </Step>
  <Step title="Name and Save">
    Give it a name like "Quick Start Test" and save the key immediately
  </Step>
</Steps>

<Warning>
  The API key is only shown once! Copy it now and store it securely.
</Warning>

## Step 2: Test Your Connection

Verify your API key works by listing test cases:

```bash
curl -X GET https://testlab.letsmake.com/api/test-cases \
  -H "X-API-Key: tlk_your_api_key_here"
```

You should receive a JSON response with your test cases (or an empty array if you haven't created any yet).

## Step 3: Create Your First Test Case

Create a simple login test case:

```bash
curl -X POST https://testlab.letsmake.com/api/test-cases \
  -H "X-API-Key: tlk_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "User can login with valid credentials",
    "description": "Verify that users can successfully log in with correct credentials",
    "preconditions": "User account exists in the system",
    "steps": [
      {
        "id": "step1",
        "description": "Navigate to login page",
        "expectedResult": "Login form is displayed"
      },
      {
        "id": "step2",
        "description": "Enter valid username and password",
        "expectedResult": "Credentials are accepted"
      },
      {
        "id": "step3",
        "description": "Click login button",
        "expectedResult": "User is redirected to dashboard"
      }
    ],
    "labels": ["authentication", "critical"],
    "automationStatus": "not_automated"
  }'
```

Save the returned `id` - you'll need it for the next steps.

## Step 4: Create a Test Suite

Group your test cases into a suite:

```bash
curl -X POST https://testlab.letsmake.com/api/test-suites \
  -H "X-API-Key: tlk_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Authentication Tests",
    "description": "Test suite for user authentication features",
    "testCaseIds": ["YOUR_TEST_CASE_ID_HERE"]
  }'
```

Save the suite `id` for the next step.

## Step 5: Create a Test Execution

Start a test execution run:

```bash
curl -X POST https://testlab.letsmake.com/api/executions \
  -H "X-API-Key: tlk_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "suiteId": "YOUR_SUITE_ID_HERE",
    "suiteName": "Authentication Tests",
    "testCaseIds": ["YOUR_TEST_CASE_ID_HERE"],
    "name": "Quick Start Test Run",
    "version": "v1.0.0",
    "environment": "development"
  }'
```

## Step 6: Update Test Results

Mark a test as passed or failed:

```bash
curl -X POST https://testlab.letsmake.com/api/executions/YOUR_EXECUTION_ID/results \
  -H "X-API-Key: tlk_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "results": [
      {
        "testCaseId": "YOUR_TEST_CASE_ID_HERE",
        "status": "pass",
        "notes": "Login successful, all steps passed"
      }
    ]
  }'
```

## Congratulations! 🎉

You've successfully:
- ✅ Created an API key
- ✅ Created a test case
- ✅ Created a test suite
- ✅ Started a test execution
- ✅ Recorded test results

## Troubleshooting

<AccordionGroup>
  <Accordion title="401 Unauthorized Error">
    - Verify your API key is correct
    - Check that the key is active (not disabled)
    - Ensure you're including the `X-API-Key` header
  </Accordion>

  <Accordion title="404 Not Found Error">
    - Verify the resource ID exists
    - Check that you're using the correct endpoint URL
    - Ensure you have access to the resource
  </Accordion>

  <Accordion title="400 Bad Request Error">
    - Check your request body JSON is valid
    - Verify all required fields are included
    - Ensure field values match the expected format
  </Accordion>
</AccordionGroup>

## Environment Variables

For security, store your API key in an environment variable:

```bash
# .env
TESTLAB_API_KEY=tlk_your_api_key_here
TESTLAB_BASE_URL=https://testlab.letsmake.com
```

Then use it in your scripts:

```javascript
const API_KEY = process.env.TESTLAB_API_KEY;
const BASE_URL = process.env.TESTLAB_BASE_URL;
```

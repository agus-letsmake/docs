## Overview

Prefer **`@ovenbits/make-testlab-playwright`** (and the shared Client package) for
CI reporting. Configure secrets once, push on every run, review under **Runs**.

For a shorter recipe see [GitHub Actions reporting](/docs/ci-automations/github-actions).

## Prerequisites

- Project-scoped API key (`TESTLAB_API_KEY`)
- `TESTLAB_URL` and `TESTLAB_PROJECT_ID`
- Playwright tests with automation keys (tags or titles)

## Playwright (recommended)

### 1. Install

```bash
npm install @ovenbits/make-testlab-playwright @ovenbits/make-testlab-client
```

### 2. Register the reporter

```ts
import { defineConfig } from "@playwright/test";

export default defineConfig({
  use: { screenshot: "on" },
  reporter: [["list"], ["@ovenbits/make-testlab-playwright"]],
});
```

### 3. GitHub Actions example

```yaml
- name: Install dependencies
  run: npm ci

- name: Run Playwright with TestLab reporting
  env:
    TESTLAB_URL: ${{ secrets.TESTLAB_URL }}
    TESTLAB_API_KEY: ${{ secrets.TESTLAB_API_KEY }}
    TESTLAB_PROJECT_ID: ${{ secrets.TESTLAB_PROJECT_ID }}
    TESTLAB_PUSH: "1"
  run: npx playwright test
```

### 4. Optional cleanup ownership

If CI owns completion:

```yaml
env:
  TESTLAB_DEFER_COMPLETE: "1"
```

Then call Client `completeExecution` / reconcile in a final job step.

## Non-Playwright runners

Use [`@ovenbits/make-testlab-client`](/docs/cli-sdk/client) directly
(`startExecution` → `pushResults` → `completeExecution`).

## Legacy Jest JSON script

Older Jest converter scripts may still exist in historical repos. Prefer the
Client package for new work. If you must map Jest JSON yourself, post to
`POST /api/automated-results` with `X-API-Key` and `X-Project-Id` — see
[API reference](/docs/api-reference/automated-results/push).

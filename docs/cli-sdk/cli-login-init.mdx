The Playwright package ships a setup-only `testlab` binary. There is **no**
`sync` command. Day-to-day reporting is the reporter (or Client), not ongoing CLI use.

## Login

```bash
npx testlab login --url https://your-testlab-host
```

Opens [CLI device login](/docs/web-app/cli-device-login). Stores a short-lived user
credential outside the repo.

## Init

```bash
npx testlab init
```

Select or create a Project, issue a CI API key, and upsert **only** `TESTLAB_*`
keys into `.env`. Prompts before replacing an existing `TESTLAB_API_KEY`.

Does **not** import Catalog or create/link suites.

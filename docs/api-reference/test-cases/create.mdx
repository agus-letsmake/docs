---
title: "Create Test Case"
api: "POST /api/test-cases"
description: "Create a new test case with steps and metadata"
---

## Overview

Create a new test case in the system. The test case will be automatically associated with the authenticated user as the creator.

## Authentication

This endpoint requires authentication via API key or Bearer token.

<ParamField header="X-API-Key" type="string">
  Your API key for authentication
</ParamField>

<ParamField header="Authorization" type="string">
  Bearer token (Firebase ID token)
</ParamField>

## Request Body

<ParamField body="title" type="string" required>
  Test case title (must be unique and descriptive)
</ParamField>

<ParamField body="description" type="string">
  Detailed description of what this test case validates
</ParamField>

<ParamField body="preconditions" type="string">
  Prerequisites that must be met before executing the test
</ParamField>

<ParamField body="epicOrFeature" type="string">
  The epic or feature this test case belongs to
</ParamField>

<ParamField body="steps" type="array">
  Array of test steps to execute
  <Expandable title="Step properties">
    <ParamField body="id" type="string" required>
      Unique identifier for the step (e.g., "step1", "step2")
    </ParamField>
    <ParamField body="description" type="string" required>
      Description of the action to perform
    </ParamField>
    <ParamField body="expectedResult" type="string" required>
      Expected outcome of the step
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="labels" type="array">
  Array of label strings for categorization (e.g., ["smoke-test", "critical"])
</ParamField>

<ParamField body="automationStatus" type="string" default="not_automated">
  Automation status. One of: `not_automated`, `automated`, `will_not_automate`
</ParamField>

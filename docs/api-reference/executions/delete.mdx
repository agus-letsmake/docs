---
title: "Delete Execution"
api: "DELETE /api/executions/{id}"
description: "Delete a test execution by ID"
---

<ParamField path="id" type="string" required>
  The unique identifier of the execution to delete
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE https://testlab.letsmake.com/api/executions/exec123 \
  -H "X-API-Key: tlk_your_api_key_here"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "success": true
}
```
</ResponseExample>

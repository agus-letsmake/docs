Three related surfaces:

1. **Reporting from CI** — Client / Playwright packages with `TESTLAB_*` secrets
2. **Automations** — in-app GitHub App wiring to dispatch workflows (`/automations`
   and Project → Automation)
3. **Live Slack run cards** — TestLab posts and updates one Slack plan per
   automated execution; enable per project, not in CI secrets

Start with [GitHub Actions](/ci-automations/github-actions) for the reporting
path, then [Automations](/ci-automations/automations) if you need TestLab to
trigger workflows. Slack: [Live Slack run cards](/guides/live-slack-run-cards).

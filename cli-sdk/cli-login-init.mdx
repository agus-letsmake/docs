The Playwright package ships a setup-only `testlab` binary. There is **no**
`sync` command. Day-to-day reporting is the reporter (or Client), not ongoing CLI use.

## Login

```bash
npx testlab login
```

Opens [CLI device login](/web-app/cli-device-login) on the hosted app
(`https://make-testlab.vercel.app`). Pass `--url` only for a self-hosted instance. Stores a short-lived
user credential **outside the repo**:

`$XDG_CONFIG_HOME/testlab/credentials.json` (or `~/.config/testlab/credentials.json`).
File mode `0600`. This is not a CI API key and must never be copied into `.env`.

## Init

```bash
npx testlab init
```

Select or create a Project, issue a CI API key, and upsert **only** `TESTLAB_*`
keys into `.env`. Prompts before replacing an existing `TESTLAB_API_KEY`.

Does **not** import Catalog or create/link suites.
